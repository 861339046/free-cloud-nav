前 6 篇教程（Oracle / Supabase / R2 / Vercel / Neon / Workers）都在讲「海外免费云」。但中文流量变现有一道绕不开的坎：国内访问速度与备案。Cloudflare Pages 免备案也能用，可如果你要的是真正的国内低延迟、要跑常驻后端（爬虫 / 机器人 / 定时任务）、要一个能正规矩阵的中文站，就必须有一台境内服务器 + 一个已备案域名。

腾讯云轻量应用服务器（Lighthouse）就是这条路上最便宜的一档：套餐制、开箱即用、带公网 IP 和流量包，新人首单常见 ¥38/年起。Oracle 永久免费实例解决「有没有服务器」，轻量解决「服务器在不在国内、合不合规」——两者不冲突，是互补的。

本篇定位与其它教程不同，先说清楚：轻量不是永久免费产品，它的价值是「用几十元/年换一台境内完整的服务器控制权」。新用户可以先薅免费试用再决定要不要买。价格随活动频繁变动，本文数字仅为实测观察值，一律以腾讯云官方活动页为准。

一、先把「多少钱」说清楚

轻量的成本结构比免费服务复杂，因为它有两层：首购价（很便宜，拉新）和续费价（按官网价，通常贵好几倍）。下单前一定要把这两层分开算。

三、适合用它做什么

  • 境内中文站 / 博客：国内低延迟 + 可备案，百度抓取与收录都更友好。
  • 常驻后端服务：Node / Python 的爬虫、Telegram 或微信机器人、定时任务、API 服务——这些在 Serverless 免费层上跑不稳的东西。
  • 自建小数据库 / 缓存：MySQL、Redis 装在本地，配 Neon / Supabase 做异地备份。
  • 中转 / 反代 / 内网穿透：给自己搭一个稳定的跳板或反向代理入口。
  • 不适合：纯静态站（Pages 免费且更快）、需要秒级弹性伸缩的业务、想完全零成本的项目。

四、开通全流程（实测 8 步）

  1. 注册 + 实名认证。进 cloud.tencent.com 注册，个人认证上传身份证即可。未实名无法购买服务器。
  2. 选地域。境内选 广州 / 上海 / 北京 / 成都 / 南京（延迟最低、要备案）；不想备案就选中国香港 / 新加坡 / 东京 / 硅谷 等境外节点，即买即用。轻量目前支持的地域还包括首尔、法兰克福、雅加达、弗吉尼亚、曼谷、圣保罗、新山等。
  3. 选镜像。应用镜像（宝塔面板 / LAMP / WordPress / Docker）买完就直接能用，适合新手；系统镜像（Ubuntu 22.04 / Debian 12）干净可控，适合要自己掌控环境的进阶用户。
  4. 选套餐 + 购买时长。记得：备案要求包年包月且购买时长 ≥ 3 个月，打算正规建站就一次买长一点。
  5. 放行防火墙端口。控制台 →【防火墙】→ 添加规则，放行 22（SSH）/ 80 / 443；用宝塔还要加 8888。
  6. 重置密码或用密钥。【概要】里重置 root 密码（或绑定 SSH 密钥），拿到公网 IP。
  7. SSH 登录。ssh root@你的公网IP，登录成功后先 apt update 或 yum update 更一遍系统。
  8. 部署应用 → 解析域名。部署方式见下一节；境内节点要先把域名备案完成才能解析，否则会被拦截。

五、最小可用示例（三种常见部署）

A. Nginx 托管一个静态站（最省资源，个人站首选）：

sudo apt update && sudo apt install -y nginx
sudo mkdir -p /var/www/mysite
# 把站点文件传进 /var/www/mysite（scp / git clone / 宝塔上传均可）
sudo nano /etc/nginx/sites-available/default   # root 指向 /var/www/mysite
sudo nginx -t && sudo systemctl reload nginx

B. Node 应用常驻（pm2 守护进程）：

curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs
sudo npm i -g pm2
pm2 start app.js --name myapp
pm2 save && pm2 startup   # 开机自启

C. Docker 一把梭：

sudo apt install -y docker.io
sudo docker run -d --restart=always -p 8080:80 nginx

最后用 Nginx 反向代理把 8080 转到 80，应用就走上了标准 HTTP 端口：

server {
    listen 80;
    server_name your-domain.com;
    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}

六、防火墙：最常把人卡住的一步

轻量的防火墙（安全组）是独立于系统 iptables 的一层，两边都要通。默认只放行少量常用端口，你自己起的服务端口必须手动加规则。

⚠️ 踩坑 2 — 症状「SSH 里服务明明启动了，浏览器/别的机器就是连不上」= 99% 是防火墙没放行端口。对策：控制台【防火墙】→ 添加规则 → 协议 TCP → 端口填你的服务端口 → 来源建议限自己的 IP 段，别图省事全网放行。
⚠️ 踩坑 3 — 数据库端口不要对全网开放。3306（MySQL）/ 6379（Redis）/ 27017（MongoDB）一旦暴露在公网，几小时内就会被爆破扫描。对策：只允许本机或固定 IP，或干脆走 SSH 隧道访问。

七、域名与备案（境内节点的硬门槛）

结论先说：域名只要解析到境内节点，就必须完成 ICP 备案，未备案会被腾讯云的未备案监测系统直接阻断访问并跳转提示页——这是「被拦截」，不是「跑得慢」，也没有端口可以绕（不论 80 还是 8080 都能被监测到）。

备案的前提条件（官方口径）

  • 服务器在 中国境内，计费模式为包年包月，购买时长 ≥ 3 个月（含续费），且备案期间剩余有效期 ≥ 1 个月；
  • 中国香港及境外节点无需备案，也不能用于备案；
  • 域名需完成实名认证，且实名信息与备案主体一致；
  • 个人账号下，同一台轻量实例最多备案 5 个网站 / APP。
⚠️ 踩坑 4 — 免费二级域名（比如本站用的 eu.org）不能备案。想上境内节点正规建站，必须有一个可备案的域名（.cn / .com / .net 等），且在境内注册商处完成实名。这是很多人买了境内服务器之后才发现卡住的地方。

备案流程与时间

  1. 在腾讯云控制台提交备案：填主体信息（身份证）、域名、关联网轻量实例。备案本身免费。
  2. 腾讯云初审：约 1–2 个工作日，核对资料真实性后提交管局。
  3. 短信核验：部分省份（如广东、天津）需在收到工信部短信后 24 小时内完成核验，超时会自动退回。
  4. 管局审核：各省 3–20 个工作日不等，广东约 7–10 个工作日。
  5. 下发备案号：拿到 ICP 备案号后，域名才能正式解析到境内节点对外服务。

备案全程要给网站留出「空窗期」——这段时间域名不能解析到境内服务器，你可以先用公网 IP 调试，或先挂到境外节点 / Cloudflare Pages 上顶着。

💡 不想折腾备案？选 中国香港节点：免备案、买完即用、国内访问延迟只比境内高 30–80ms（对博客 / 工具站完全可以接受）。代价是——严格来说不算「合规的境内站」，部分场景浏览器会提示未备案。

八、8 个真实踩坑提醒

⚠️ 踩坑 5 — 套餐里的「月流量」是打包限额，超了要额外掏钱或限速。轻量的带宽和流量是一次性打包出售的（比如 4M 带宽 + 300GB/月），一旦超量，要么按量计费补钱，要么被降速。对策：图片、视频、安装包这类静态大资源放 Cloudflare R2（免出口流量费），给服务器省流量。
⚠️ 踩坑 6 — 快照回滚不可逆，且不会自动开。轻量快照需要手动创建（或自行配置自动备份策略）；回滚会把整盘数据覆盖回快照时刻的状态，之后产生的数据全部丢失，删掉的快照同样无法恢复。对策：重要数据定期异地备份到 R2 / B2，别把快照当唯一保险。
⚠️ 踩坑 7 — 到期不续费会停机，保留期过后实例释放、数据清空。包年包月到期后一般有几天到十几天的停机保留期，逾期未续费实例会被回收，系统盘数据随之清除。对策：开「自动续费」，并养成定期导出数据的习惯。
⚠️ 踩坑 8 — 选错镜像 / 重装系统会清空系统盘。应用镜像里预装的宝塔面板默认占用 8888 端口，而宝塔是全网被扫最多的入口之一。对策：装完立刻改默认端口 + 强密码 + 登录 IP 白名单；并记住「重装系统 = 系统盘全清」，数据盘不受影响但也别赌。

九、什么时候该买，什么时候别买

  • 该买：要国内低延迟访问、要跑常驻后端（爬虫 / 机器人 / 定时任务）、要备案做正规中文站、要完整 root 控制权。
  • 别买：纯静态站（Cloudflare Pages 免费且全球更快）、只是想要「有一台服务器」（Oracle 永久免费实例 更合适）。
  • 成本视角：¥38–99/年 ≈ 每月 3–8 元，比一杯饮品便宜；但一定要把「续费价」和「流量超额」两笔潜在支出算进去。
💡 组合拳（境内 + 海外双活）：腾讯云轻量（境内节点，跑主站 + 后端 + 本地数据库） + 已备案域名 = 国内最快最稳；静态资源交给 R2 省流量，图片走 CDN，边缘逻辑交给 Workers，免费后端用 Supabase / Neon，海外可达性由 Vercel / Pages 兜底。境内合规主站 + 海外免费边缘，是中文小产品性价比最高的形态。

十、诚实边界

轻量不是免费产品，本篇以「低成本入场 + 国内合规落点」定位收录，与本站其余免费教程互补。文中价格均为活动期观察值，腾讯云的促销节奏、套餐配置、备案政策与管局审核时长都会变动，一切以腾讯云官方页面与实际控制台为准。本站不构成任何购买建议，与腾讯云无返利关系。
