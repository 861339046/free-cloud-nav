本网站为个人维护的非商业导航 / 教程站点。我们不会主动出售您的个人信息。本政策依据《个人信息保护法》及主要第三方服务（Google AdSense、Cloudflare）的要求制定。

一、我们收集的信息

本站在您仅浏览时不收集任何可识别身份的个人信息。仅在以下情况会收到您主动提供的信息：

  • 商务合作 / 付费收录：您通过邮件或 GitHub Issue 联系我们时，会提供您的邮箱或昵称。
  • 提交收录：您通过 GitHub Issue 提交服务信息时，内容由 GitHub 代管。

二、Cookie 与同类技术

为提升访问体验与站点运营，本站使用以下技术：

  • Cloudflare Web Analytics：匿名统计访问量、来源与页面热度，不追踪个人身份。
  • 百度主动推送：仅向百度站长平台上报页面 URL 以加速收录，不含个人信息。
  • Google AdSense（即将启用）：启用后，Google 及其合作伙伴会通过 Cookie 投放与您兴趣相关的广告。您可在 Google 广告设置 中关闭个性化广告。

三、第三方广告

本站计划接入 Google AdSense 作为变现方式。AdSense 可能使用 Cookie（如 NID、IDE）基于您的过往访问行为投放个性化广告。第三方广告商可能独立收集信息，其做法受各自隐私政策约束，本站不对此负责。您可通过 Google 广告设置 或 aboutads.info 管理偏好。

四、数据共享

除下列情形外，我们不会与第三方共享您的个人信息：

  • 为展示广告而必要的技术传递（如 AdSense 所需的 Cookie）；
  • 法律法规要求或司法机关依法调取。

五、您的权利

您有权查询、更正或删除我们持有的您的个人信息。如需行使权利，请通过页脚邮箱联系我们，我们将在合理时间内响应。
