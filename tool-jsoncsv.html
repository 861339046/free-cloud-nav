转换规则说明

  • JSON → CSV：表头取所有对象键的并集，缺失字段留空；值为对象或数组时以 JSON 字符串整体写入单元格并加引号转义；
  • CSV → JSON：按 RFC 4180 解析——双引号包裹的字段里，逗号、换行、连续两个双引号（"" 即引号本身）都不会切断字段；
  • 勾选「数字转数值类型」时，纯数字（含负数与小数）的单元格会转成 number，其余保持字符串；空字符串保持 ""；
  • 第一行必须是表头。分隔符选「制表符」即可处理从 Excel 直接复制出来的 TSV 片段。
转换全部在浏览器本地完成，粘贴的数据不会上传到任何服务器。
