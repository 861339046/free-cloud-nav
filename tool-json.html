常见报错对照

  • Unexpected token ' in JSON —— 用了单引号。JSON 的字符串必须用双引号，键名也要双引号；
  • Unexpected token } / , —— 末尾多了逗号（trailing comma）。JSON 不允许最后一项后带逗号；
  • Unexpected token n —— 写了 NaN / undefined。JSON 只接受 null；
  • Unexpected end of JSON input —— 括号没配对，或复制时截断了；
  • 中文乱码 —— 一般是上游按 GBK 编码而您按 UTF-8 解析，先确认响应头 charset。
