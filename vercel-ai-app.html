Vercel 是目前最主流的前端部署平台，对 Next.js 等框架几乎「一键上线」。它的 Serverless Functions（函数）能在不用自己买服务器的情况下，跑后端逻辑——比如调用大模型 API，做一个 AI 小工具（周报生成器、文案润色、简历改写）。对本站一贯的「零成本起步、跑通再投入」思路，Vercel 是验证 AI 点子的最低门槛入口。

本篇是实测向教程，重点在「Hobby 免费层给多少」和「哪里会踩坑」，并专门讲清变现边界（这关系到您这个站最终要不要靠它赚钱）。控制台入口：vercel.com，可用 GitHub 账号登录。

Vercel 的免费计划叫 Hobby，下面这些量级是 2026 年实测到的，做 AI 小工具前心里先有数：

⚠️ 踩坑 1（最关键，关于「赚钱」）—— Hobby 计划禁止商用。Vercel 条款明确：Hobby 仅用于个人、非商业、学习用途，不能用来赚钱（盈利活动、商业产品）。您的「免费云导航」如果未来接 AdSense、或这个 AI 工具收费，就超出了 Hobby 许可范围，必须升级 Pro（约 $20/月）。这是本站「变现拐点」的真实成本，别等被风控才补。

二、适合用它做什么

  • 验证 AI 点子：先用 Hobby 把工具做出来、给人试用，零服务器成本跑通闭环（本站「跑通再投入」思路）。
  • 个人小工具 / 作品集：不收费的 AI 助手、简历润色器，纯自用或展示。
  • 和本站矩阵搭配：前端在 Vercel，数据进 Supabase、大文件走 Cloudflare R2、常驻服务用 Oracle 免费实例。
  • 不适合（Hobby 下）：任何收费产品、高并发、长耗时任务、需要团队协作权限的商业项目。

三、开通全流程（实测步骤）

  1. 注册 / 登录。打开 vercel.com，用 GitHub 账号登录（免密、且与您 已有的 GitHub 打通）。
  2. 导入或新建。点 Add New → Project，选「Import Git Repository」导入您仓库，或「Deploy」一个模板（如 Next.js 模板）。
  3. 选框架。Vercel 会自动识别（Next.js / Vite / 纯静态）。纯函数小工具推荐 Next.js（自带 API Route）。
  4. 配环境变量。在 Environment Variables 里加上大模型 API Key，如 OPENAI_API_KEY、API_BASE_URL。切勿写成 NEXT_PUBLIC_ 前缀（见踩坑 5）。
  5. 部署。点 Deploy，Vercel 拉代码构建，几秒到几分钟出 xxx.vercel.app 临时域名。绑定自定义域在 Settings → Domains。
  6. （变现时）升级 Pro。一旦要收费，进 Settings → Plan 切到 Pro，再合规部署商业版本。

四、最小可跑示例（调大模型）

一个 Next.js 的 API Route（app/api/chat/route.ts），在服务端用环境变量调模型，密钥不暴露给浏览器：

export async function POST(req: Request) {
  const { prompt } = await req.json()
  const res = await fetch(process.env.API_BASE_URL!, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      Authorization: `Bearer ${process.env.OPENAI_API_KEY}`
    },
    body: JSON.stringify({
      model: 'gpt-4o-mini',
      messages: [{ role: 'user', content: prompt }]
    })
  })
  const data = await res.json()
  return Response.json({ reply: data.choices[0].message.content })
}

前端只 fetch('/api/chat') 即可。注意：模型 API 本身要钱（见踩坑 6），Vercel 的免费只覆盖「托管和函数」，不覆盖「调模型」。

五、7 个真实踩坑提醒

⚠️ 踩坑 2 — 函数超时 10 秒。Hobby 的函数最长跑 10 秒，而大模型首字延迟（TTFT）慢、生成长文本时很容易超时返回 504。对策：用流式响应（streaming）、换更快的小模型（如 mini 系列）、或升级 Pro 把超时提到 60s+。
⚠️ 踩坑 3 — 并发只有 1。Hobby 同一时刻只处理 1 个函数请求，第二个人访问会排队甚至失败。个人试用没事，一旦有点流量就卡。对策：真有用户就升级 Pro（并发提升），或把重逻辑挪到 Supabase Edge / Cloudflare Workers。
⚠️ 踩坑 4 — 默认部署在美国，国内访问慢。Vercel 免费节点主要在美/欧，广州用户打开可能要 1–2 秒甚至更久。对策：用 Edge Functions 把轻量逻辑放边缘节点；或用 Cloudflare 做反代加速（结合本站 R2 篇）。
⚠️ 踩坑 5 — 环境变量前缀泄露。Vercel 里 NEXT_PUBLIC_ 前缀的变量会被打进前端 JS、任何人能在浏览器看到。API Key 必须用普通名（如 OPENAI_API_KEY）只在服务端读，否则密钥被盗刷。
⚠️ 踩坑 6 — Vercel 免费 ≠ 模型免费。很多人以为「Vercel 免费部署 AI 应用就零成本」，其实函数托管免费，但每次调大模型都要向模型厂商付费（OpenAI / 国内模型都有价）。对策：用有免费额度的模型（如各家入门档）、加缓存避免重复调用、做使用上限防刷。
⚠️ 踩坑 7 — 超额不会自动停，会出账单/暂停。Hobby 超了带宽或函数额度，可能暂停部署或产生按量费用（尤其函数 GB-hr 失控）。对策：在 Settings → Usage 看实时用量，给函数加超时与频率限制，避免被刷爆。
💡 组合拳与本系列定位：Vercel（前端+函数）+ Supabase（数据/登录）+ R2（大文件）+ Oracle（常驻服务）= 一个「几乎零成本验证、跑通再付钱」的全栈底座。本站前几篇分别讲了每一块；Vercel 是让「AI 小应用」最快上线的入口，但记住踩坑 1：要赚钱先升 Pro。

六、什么时候该付费

出现下面任一信号，说明 Hobby 到顶、该升级 Pro（约 $20/月）：① 您这个工具或站点开始收费 / 接广告；② 并发不够、用户排队；③ 函数老超时；④ 需要团队协作、预览环境权限、更多域名。升级后这些限制大幅放宽，且合规商用。一句话：Vercel 帮您零成本验证点子，赚钱那一步的成本是每月 $20，不是零。
