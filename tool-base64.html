Base64

URL 编码（Percent-Encoding）

为什么中文 Base64 到处乱码？

因为 btoa() 这类函数只认「每字符一字节」的 Latin-1。中文是 UTF-8 多字节字符，必须先 TextEncoder 转成字节流再编码。本工具就是按 UTF-8 → 字节 → Base64 的正确链路实现的，与 atob → TextDecoder 对称解码，中文、emoji 都不丢。

  • 看到 %E4%BD%A0%E5%A5%BD 是 URL 编码；看到 5L2g5aW9 是 Base64——两者底层都是同一串 UTF-8 字节；
  • JWT 的三段 payload 就是 URL-Safe Base64（-_ 替代 +/、去 = 填充），用「解码 ← Base64」配合本站 JSON 工具可直接看内容（注意 JWT payload 不含签名验证，仅用于调试查看）；
  • Base64 不是加密，只是编码——任何人都能解码，别用来藏密码。
