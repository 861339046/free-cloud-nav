说明

  • 能检查什么：公钥格式是否合法、密钥类型（ed25519 / RSA / ECDSA，含硬件密钥 sk-）、RSA 位数（<2048 标红告警）、SHA256 指纹（OpenSSH 的 SHA256:xxxx 格式，可与 ssh-keygen -lf 输出对照）、注释；
  • 私钥配对：支持未加密的 OpenSSH 新格式（BEGIN OPENSSH PRIVATE KEY）、RSA PKCS#1（BEGIN RSA PRIVATE KEY）与 PKCS#8（BEGIN PRIVATE KEY）；加密的私钥会提示无法解析——请用 ssh-keygen -y -f 私钥文件 在本机导出公钥后再来比对；
  • 连接测试做不了：浏览器无法发起 SSH 协议的 TCP 连接，真实登录测试请在终端 ssh -v user@host 排查；
  • 隐私：解析全部在本页内存完成，无任何网络请求；校验完建议清空输入框并关闭页面。
