排错速用

  • 403 但登录态正常：先看响应头有没有 CF-Ray / Server——CDN 或 WAF 拦截会伪装成 403，服务端日志里根本查不到；
  • 502/504 分不清：502 是网关拿到了错误响应（后端挂了或返回了非 HTTP 内容），504 是网关等超时（后端还在算但太慢）；
  • 404 但文件确实在：大小写敏感、URL 编码、路径重写规则、SPA 缺 history fallback 是四大常见原因；
  • CORS 报错：看的是「预检 OPTIONS 的响应头」而不是最终请求的——后端处理了 OPTIONS 才算数。
